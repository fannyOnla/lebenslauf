## Schwerpunkt: KI in der Anwendung

In meiner Abschlussarbeit binde ich mehrere KI-Dienste als eigenständige Services an eine Webanwendung an:

- **LLM-Anbindung** über eine REST-API (Ollama, Llama/Qwen) für einen Konversationsassistenten
- **Prompt-Design und -Tests** für verschiedene Gesprächsmodi — freies Gespräch, Vokabelübung, Grammatik
- **Speech-to-Text und Text-to-Speech** (Whisper/MMS, Coqui XTTS) für Spracheingabe und Sprachausgabe
- **Streaming über WebSocket**, damit Audio- und Textantworten in Echtzeit im Frontend ankommen
- **Kuratierung von Trainingsdaten** und Export validierter Datenpaare für das Fine-Tuning

Was ich dabei gelernt habe: KI-Ausgaben sind ein Vorschlag, kein Ergebnis. Jede Antwort braucht Validierung — im Projekt durch Muttersprachler, im Code durch Tests.

## Projekte

### 🗣️ KI-Bassa — KI-gestützte Sprachlernplattform *(Bachelorarbeit)*
`Java 21` `Spring Boot 3` `React` `PostgreSQL` `Docker` `LLM` `WebSocket`

Lernplattform für Bassa, eine bedrohte Bantusprache aus Kamerun, für die es bisher keine
digitalen Lernressourcen gibt. Vier Komponenten in einer Docker-Compose-Umgebung: ein KI-Stack
aus STT-, LLM- und TTS-Microservices, eine Spring-Boot-API als Orchestrierungsschicht, ein
React-Frontend und eine PostgreSQL-Datenbank als Sprachkorpus.

Umgesetzt unter anderem: Aussprachetrainer mit phonemweiser KI-Bewertung, Konversationsassistent
mit Audio-Ein- und Ausgabe, Spaced-Repetition-Lernalgorithmus (SM-2), JWT-Authentifizierung,
CI/CD-Pipeline und versionierte Datenbankmigrationen.

### 🏠 Immobilien-Vermietungsplattform
`Spring Boot` `Vue.js` `Node.js` `MySQL` `REST`

Getrennte Ansichten für Eigentümer und Mietinteressenten, automatische E-Mail-Benachrichtigung
bei passenden Angeboten, Anbindung von Frontend und Backend über REST-Schnittstellen,
Unit- und Integrationstests.

### 📚 Online-Bibliotheksplattform für Universitäten
`PHP` `JavaScript` `MySQL` `Bootstrap` `Linux`

Entwurf von Datenmodell und Schema; Buchung und Stornierung von Büchern, Registrierung von
Studierenden und Lehrenden.
